HOW THIS EXPORT WAS PRODUCED — PLEASE READ
-------------------------------------------------------------------
The working copy was lost part-way through this request: the
container running the build was reset and its filesystem wiped.

Rather than reassemble the site by hand, it was rebuilt by replaying
the original 6.5 full state through all twenty-four delta bundles in
order. That is verifiable, and it verified: each release's ?v=
address appeared in the expected sequence as its bundle was applied,
6.5's e32c702b through to 9b0bdf51, and the stylesheet address
stamped on all eighteen pages matches the hash computed from the
final css and js. The reconstruction is exact.

So what you are uploading is the same site you have been approving,
not an approximation of it.


ONE THING THAT DID NOT SURVIVE — AND IT MATTERS
-------------------------------------------------------------------
build_ttd.py, the generator for things-to-do.html, was lost with the
container. The only copy that survives is the one from the original
6.5 upload, and it predates every markup change made since: the
hook, the ANAHIM LAKE block and "Explore a little further" removals,
the skates graphic and its dotted route, the mobile carousels and
the slide wrappers around them.

RUNNING IT WOULD OVERWRITE things-to-do.html WITH THE 6.5 MARKUP and
undo all of that. It is deliberately NOT included in this export.

things-to-do.html is now the source of truth for that page. Next
time it needs changing, either edit the HTML directly or rebuild the
generator from the current page first. The page itself is complete
and correct — this is a lost tool, not a broken site.
