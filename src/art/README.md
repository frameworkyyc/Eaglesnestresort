# Eagle's Nest illustration set (Style B: playful linocut)

Generated with Higgsfield (Seedream 5.5), transparent backgrounds, no text in any image.
Web files only (AVIF primary, WebP fallback). 2K master PNGs are kept outside the repo.

Style block used in every prompt:
"Playful linocut-print illustration, bold chunky shapes, thick uniform dark outline, simplified bold
hatching, flat spot colours with slight misregistration, warm storybook personality, still clearly
vintage national park poster art. Palette: spruce #153B33, lake teal #2A8C93, goldenrod #F2B63D,
fox orange #D9622B, cream #F5EEDC. No text, no letters, no logo, no watermark, no frame."

Characters (consistency by image reference to the approved fox-idle and eagle-glide masters):
fox-idle, fox-peek, fox-wave, fox-surprised, fox-sleep; eagle-glide, eagle-up, eagle-down, eagle-perch.
Scenery (one layer per image): far-mountains, mid-hills, lake-strip, shore-fg, clouds,
trees-summer, trees-winter; prop: canoe.

Not yet made: bear, moose, owl, hare, Oliver the Westie; trail sign, compass, map pieces;
pose variants for the eagle's head turns; more character expressions.
